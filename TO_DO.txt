Here's the current situation:               
                                          
  There's already a half-way toggle — arxiv_only=True which stops after
  stage 1 (fetch only, no scoring). But there's no equivalent flag to   
  start after stage 1 (skip fetch, score from an existing snapshot). 
                                                                        
  What does exist already is batch_tools.py resume --batch-id <id> — if 
  a batch was already submitted to Doubleword and you just need to      
  collect and write the results, that works today.                      
                                                                      
  But what you're describing — "arXiv snapshot already exists, skip     
  straight to scoring" — doesn't exist yet. It would need a        
  --from-snapshot <path> mode that:                                     
  1. Reads runs/search/arxiv_snapshot_TIMESTAMP.json to reconstruct the
  paper list                                                            
  2. Skips straight to step 2 (create batch JSONL) in daily_run        
                                                                        
  It's a reasonable feature. Want me to add it? It's probably 30-40   
  lines — mainly a new branch in daily_run that loads papers from the
  snapshot file instead of calling get_daily_papers, plus a CLI argument
   to pass the snapshot path.
